# KeyFlip — русский Punto Switcher

**Локальное приложение для Windows 10/11**, которое мгновенно переводит выделенный текст между русской и английской раскладкой (как Punto Switcher).

## Возможности

- Горячая клавиша **перевода** (по умолчанию `F4`)
- Горячая клавиша **смены регистра** (по умолчанию `Ctrl+Shift+U`)
- Горячая клавиша **выхода** (по умолчанию `F10`)
- Полностью настраиваемые комбинации
- Автозапуск с Windows
- Специальная обработка переносов строк (Shift+Enter) — не ломает Telegram, Discord и т.д.
- Компактная панель над треем в стиле NightLightTray: состояние и текущие хоткеи
- Светлая/тёмная тема вслед за Windows, меню настроек и редактор комбинаций
- Логирование в файл (по желанию)

## Установка

На компьютере, где собирается приложение:

1. Создай окружение и установи зависимости для сборки:
   ```powershell
   py -3 -m venv .venv
   .venv\Scripts\python.exe -m pip install -r requirements-build.txt
   ```

2. Установи [NSIS](https://nsis.sourceforge.io/Download) и выполни `build_installer.bat`.
   Если компилятор не в стандартной папке, передай путь к `makensis.exe` первым аргументом.

Готовый `KeyFlipSetup.exe` можно запускать на других компьютерах: установщик сам
положит EXE в выбранную папку и создаст ярлык в меню «Пуск». Python, исходники и
`.venv` там не нужны. Удаление — через «Установленные приложения» Windows.
Настройки и журналы установленной версии находятся в `%LOCALAPPDATA%\KeyFlip` и
при удалении приложения сохраняются. Автозапуск можно включить в панели KeyFlip.

Для сборки только EXE без установщика выполни `build.bat` (результат в `dist`).
Для запуска из исходников установи `requirements.txt` и выполни
`.venv\Scripts\pythonw.exe app.pyw`.

Для запуска из терминала с видимыми сообщениями об ошибках:

```powershell
.venv\Scripts\python.exe app.pyw
```

Левый клик по значку открывает панель, правый — меню. Переключатель ставит
обработку текста на паузу. Нажатие на строку горячей клавиши открывает окно ввода:
нажми нужное сочетание, и оно сохранится автоматически. `Esc` отменяет ввод.
Escape или клик вне панели закрывает её. Автозапуск и логирование переключаются
в самой панели; пресеты горячих клавиш доступны в меню правого клика.

Если запуск завершится ошибкой, приложение покажет её и сохранит подробности
в `keyflip-startup-error.log` даже при выключенном обычном логировании.
