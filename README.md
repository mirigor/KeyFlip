# KeyFlip

KeyFlip — утилита для Windows 10/11 (x64), которая по горячей клавише исправляет
раскладку **выделенного текста** между русским и английским языками. Она также
умеет менять регистр выделения. Это действие по запросу пользователя, а не
автоматическое переключение раскладки при наборе текста.

## Возможности

- Смена раскладки выделенного текста — `F4` по умолчанию.
- Изменение регистра выделенного текста — `Ctrl+Shift+U`.
- Выход из приложения — `F10`.
- Настройка сочетаний, пауза, автозапуск и файловое логирование через панель в трее.
- Пресеты сочетаний в меню по правому клику; светлая и тёмная тема вслед за Windows.
- Сохранение переносов строк при вставке преобразованного текста.

## Установка и использование

Запусти `KeyFlipSetup.exe`. Установщик предложит папку установки (по умолчанию
`%LOCALAPPDATA%\Programs\KeyFlip`) и создаст ярлык в меню «Пуск». На компьютере,
где запускается установщик, Python, исходники и `.venv` не нужны.

После запуска KeyFlip появится в системном трее. Выдели текст и нажми `F4`, чтобы
исправить раскладку, или `Ctrl+Shift+U`, чтобы изменить регистр. Левый клик по
значку открывает панель, правый — меню. В панели можно приостановить обработку,
включить автозапуск и логирование. Нажатие на строку сочетания открывает окно
выбора клавиш; `Esc` отменяет ввод.

Удалить приложение можно через «Установленные приложения» Windows. Настройки и
журналы установленной версии лежат в `%LOCALAPPDATA%\KeyFlip` и сохраняются
после удаления. Ошибки запуска записываются в `keyflip-startup-error.log` даже
при выключенном обычном логировании.

## Сборка из исходников

На компьютере для сборки нужны Python 3.10 и [NSIS](https://nsis.sourceforge.io/Download):

```powershell
py -3.10 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-build.txt
.\build_installer.bat
```

Если `makensis.exe` находится не в стандартной папке, передай его путь первым
аргументом `build_installer.bat`. Результат — `KeyFlipSetup.exe` в корне проекта.
Для сборки одного EXE без установщика используй `.\build.bat` (файл появится в `dist`).

Для запуска из исходников достаточно зависимостей из `requirements.txt`:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\pythonw.exe .\app.pyw
```

Чтобы видеть ошибки в терминале, используй `python.exe` вместо `pythonw.exe`.
